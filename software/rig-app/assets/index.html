夾閥設定（位置 / 安全上限）
找不到伺服？自動掃描
先拔掉驅動板，用一條杜邦線把 UNO Q 的 D0 和 D1 直接接在一起再按。測的是 UNO Q 自己的 D0/D1 收發是否正常，跟驅動板、伺服無關。
不需要伺服回應：用「廣播 ID」在 8 種鮑率各送一次移動指令。伺服有轉動 → 送出那條線（D1/TX）與電源正常，問題在回應那條線（D0/RX）或 TX/RX 接反；伺服完全不動 → 檢查 D1/TX 線、跳線帽、驅動板電源與伺服線。測試前請先把管子從夾頭移開。
依序試 8 種鮑率（1M、500k、250k、128k、115200、76800、57600、38400），每種先送廣播 Ping，完整掃描再逐一試 ID 0–253。找到後按「使用」就會改成那個 ID 與鮑率並存檔。掃描期間夾閥必須在「開」。
找位置的方法：按「關扭力」後用手轉夾頭，轉到剛好把管子夾扁的位置 → 按「記為夾閉」；轉回完全不壓管的位置 → 按「記為開」。或用上面的數字/±20 慢慢逼近。扭力上限可降低夾管力道與伺服發熱。TMP / Feed 上限由 MCU 每 200 ms 用瞬時峰值檢查，超過就自動放開並鎖住，Linux 端當掉也有效。

pH 探頭校正

▸
--
pH 讀值依這個溫度做 Nernst 斜率補償。請填培養液目前的溫度；會存在板子上，MCU 重開會自動還原。
標準液溫度使用溫度計：請把溫度計探頭和 pH 探頭一起放進標準液，等兩者讀值穩定再按。
步驟：探頭洗淨泡進 pH 7.00 標準液、讀值穩定後按「記為 pH 7.00」→ 洗淨泡進 pH 4.01，穩定後按「記為 pH 4.01」→ 探頭裝回反應器。校正值會存在板子上，MCU 重開會自動還原。
目前只監測與記錄 pH（加鹼控制已移除）。pH 每個取樣視窗聚合一次寫進 CSV；探頭異常（讀值超出 2–12）時該段不計入。

取樣設定

▸
壓力與流速會在這段時間內持續取樣，視窗結束時取一次中位數/平均，作為畫面上的數值、曲線圖的一點與 CSV 的一列。這個時長同時也是 OD600 的量測間隔，三個訊號永遠對齊。安全用的 TMP 瞬時峰值/谷值告警不受影響，仍然是 200ms 更新一次。

演算法切換

▸
依《訊號處理演算法檢討報告》第 2 節。預設全部是現行演算法；切換後立即生效並存檔（MCU 重開會自動推回）。每一列 CSV 的 alg_profile 欄會記錄當時的組合，事後分析可以分開比較。切換穩態判定或分析來源時，穩態與趨勢的累積會重新開始。

校正值管理

▸
輸出：把目前生效的 OD600 空白、壓力零點、光程長、pH 校正、ρgh／ΔP–Q 基準、Q_perm、夾閥設定與規格存成一個 .json 檔。輸入：選擇先前輸出的檔案，勾選要套用的項目後寫回板子。
OD600 空白基準、壓力零點 offset、光程長係數都存在 MCU 的記憶體裡，MCU 一重開就全部回到預設值。系統現在會把每次校正的結果存到板子的 Linux 側（calibration_state.json），偵測到 MCU 重開時自動推回去；你也可以在下面手動輸入自己記錄的數值。只要目前生效的值不是現場量出來的，畫面上方會持續顯示黃色提示。
