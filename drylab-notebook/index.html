The season, one frame per week

Review · Dry Lab Notebook

Works. Twenty-three weeks of dated entries, grouped by pipeline and searchable, is the record a judge goes to when they want to check whether a result on another page was really produced when the page says it was. The three views, timeline, entries and photos, give the same record three ways without duplicating it, and the keyboard hints are a real accessibility decision rather than a decoration.

Fix. The board, the entry list, the photo grid and the week strip are all built by script, so with JavaScript off this page is a hero image and a set of empty boxes; ship at least the week headings and entry titles as markup and let the script enhance them. The 160 photographs used to sit inside this file as base64 text (9.7 MB); on 25 September they were moved out to 318 WebP files in assets/img/drylab-notebook/board/, which brings the HTML to about 0.2 MB. When the media goes to static.igem.wiki, change the one path in the src helper of the page script to the upload address. Photographs 85 and 87 in the data (week 17, “Close up on the concave lens”) are the same picture entered twice, so the photo count of 160 is really 159; delete one record. Three entries name the bioreactor calculations page as a thing that happened during the season, which is correct as a record, and they should stay: no link goes back to it now that the page has been deleted. Add a line under the title saying what the record covers and what it does not, because the meta list gives 28 March to 4 September and a reader cannot tell whether later work is missing or simply unrecorded.
