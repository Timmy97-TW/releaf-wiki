Summary

Twenty‑four cultures under six defined light conditions at once. Green light induces protectant production and red halts it.

It took three design‑build‑test‑learn cycles. In Prototype 2 we measured 40 LEDs one by one (green varied by 26%, red by 22%) and matched them in fours, within 0.4–1.8%. Matching did not separate the intensity tiers, so the low, mid and high levels are set by PWM in code. Prototype 3 enclosed the array; overnight on a shaker a post snapped and the white holder leaked light between wells.

The first culture run, on 19 September 2026, grew in all six arms (3.1), but light leaked between wells, so it is not a light‑dose result. The fixes from that run are not yet re‑tested, and we have not yet run the intensity test the array was built for. Every reading here is in lux, which is weighted for human vision; it is not a biological light dose until it is converted to photon flux.

LPA: Light Plate Apparatus

The LPA is a 24‑culture LED array we built to test how wavelength and light intensity affect our CcaS/CcaR optogenetic system in engineered Bacillus subtilis. We designed it around strain 168; it first ran on WB800, the protease‑deficient strain the project moved to in September (bioreactor, 2.2). Red and green LEDs give six light conditions, with four replicate cultures each.

Three design–build–test–learn cycles made the LEDs more even, cut the light leaking between wells and moved intensity control into software (PWM). The final design is enclosed, and its light is set in code before each run.

The optogenetic system responds to light intensity and wavelength, so every well needs defined, even light. An Arduino sets the intensity by pulse‑width modulation, with one MOSFET per intensity tier, and a condition stays fixed for the whole run. The array, six columns of four with the MOSFET that drives each pair, is drawn in 4.2 Light Layout.

Engineering Cycles

Three design–build–test–learn cycles led from a breadboard array to the enclosed, software‑controlled instrument.

DBTL1

DBTL cycle 1 of 3

2.1 DBTL Cycle 1 – Dual‑Wavelength Array

One green and one red LED per column

  1. DDesignA green and a red LED per column
  2. BBuildFirst array on a breadboard
  3. TTestRed and green switch separately
  4. LLearnLED output was uneven

Design

We put a green and a red LED in each column so we could switch between them quickly and test the on/off control of protectant production directly. We calibrated nothing yet. First we wanted to know whether the idea works at all.

Build

Each column has a dual green/red LED. We printed wire‑management parts from the start, because even at this size the wiring gets messy fast, and ran the array straight from a breadboard.

Test

The red and green channels switched on and off when the code told them to. But the light output was uneven across wells, and because the green and red LEDs sat asymmetrically, the light was unbalanced from top to bottom.

Learn

The dual‑wavelength idea works, but one source of variation had to be fixed first.

LED output was inconsistent

LEDs in different wells gave different intensities at the same setting, so the low, mid and high levels were not consistent across the array, and conditions could not be compared reliably.

DBTL cycle 2 of 3

2.2 DBTL Cycle 2 – Matched Output

Every LED measured, matched in fours

  1. DDesignTiers from matched LEDs
  2. BBuildEach LED measured, then rewired
  3. TTest40 LEDs sorted into groups
  4. LLearnMatch LEDs; set tiers by PWM

Design

In Prototype 2 we worked on giving every well the same light. LEDs with very similar measured output were grouped into matched sets for each wavelength, and these sets became the low, mid and high columns.

Build

We drove each LED at 5 V and measured it on its own with a light meter, in a printed fixture that keeps the same distance and angle every time. Each LED got a tag with its row (A to D, downward) and column (1 to 5, across), so every LED can be traced back to its own reading. Then we rewired the array with the matched LEDs grouped into columns.

Test

From the 20 green and 20 red LEDs we kept twelve of each, in matched groups of four. After rewiring, these formed the six channels: low, mid and high for each wavelength.

Learn

Matching cut the variation inside each group a lot. Before sorting, the green LEDs varied by 26% and the red by 22%; after matching, the four LEDs in a group differed by only about 0.4–1.7% for green and 1.5–1.8% for red. But matching did not give three distinct intensity levels. The low, mid and high groups were still too close, especially for green. The green high group was also a little less even than the other green groups, because it was made from the LEDs left over after the first two.

So we use matching to make each column even, and set the low, mid and high levels with the PWM duty cycle instead of by picking LEDs.

Prototype 2 still had practical problems for Prototype 3 to fix. The electronics were exposed, intensity was set by hand, and the tubes had no fixed position above the LEDs and no shield from room light.

Design

Prototype 3 kept the matched LED groups and made four changes so the LPA is easier to run and to rebuild.

01 · LPA_Box

Enclosed electronicsA printed housing houses the LED wiring and the perf board, so the electronics are protected.

02 · Arduino code

Intensity in softwareLow, mid and high levels are set by PWM values in code, not by hand.

03 · Left_C, Right_C

Tool‑free assemblyPrinted sliders mean the LPA goes together and comes apart without tools.

04 · Tube_Holder

Fixed tube position and light shieldingThe tube holder keeps each culture at the same distance from its LED, run after run, and shields the tubes from room light, so only the LPA's green or red light reaches them.

Build

Test

During the overnight shaker test, one of the printed posts on the bottom plate broke off, and several wires came loose and had to be resoldered. The shaker frequency was probably too high for the print. The run also showed light leaking through the white tube holder. Each tube got light from neighboring LEDs as well as its own, which affected that run’s data (its growth readings are in 3.1).

Learn

Reinforce the base at four points

Two mounting points could not take the load. We now use all four screw positions on the bottom plate to spread it, and reinforced every solder joint. A second overnight shaker run to test these changes was started on 18 October 2026.

Block light between neighboring wells

The white tube holder let light scatter into nearby wells, so we replaced it with a black one and raised the wall thickness from 2 loops to 4, to keep each well’s light to itself.

Results

3.1 First Culture Run, 19 September 2026

On its first culture run, the LPA grew Bacillus subtilis WB800 under all six light arms to an OD600 of 0.91–1.01 at 24 h, close to the fitted plateau of 1.005.

The Run

On 19 September 2026 we grew B. subtilis WB800 under the LPA’s six light arms (red and green, each low, medium and high; R1–R3, G1–G3) and read it on a plate reader at five time points up to 24 hours.

We loaded 12 of the 24 wells, one tube in each red arm and three in each green arm. Following the team wiki’s Measurement page, each tube held 2 mL of LB inoculated with the culture, incubated at 37 °C with shaking. The plate’s temperature was not recorded during the run (Digital Twin page).

This is Prototype 3’s overnight shaker run (2.3). A post snapped and light leaked through the white tube holder into neighboring wells, so the arms are not compared as light doses. The run records the culture’s growth under the array.

Final Design & Specifications

The final LPA keeps what each cycle showed was needed (4.4). It lights 24 cultures under six fixed conditions (two wavelengths at three intensities, four replicates each) from one Arduino and three MOSFETs.

4.2 Light Layout

Each column of four is one light condition. A tier is a green and a red column on one MOSFET, so both share one duty cycle.

Why green and red?three reasons
  1. Green turns production on. Green light activates the CcaS sensor, which switches on CcaR and, through it, the production genes.
  2. Red turns it off. Red light switches CcaS back to its inactive form.
  3. So one array asks both questions. With both colors at three intensities, one run can show how strongly production follows the light and whether red stops it.

4.3 The Soldered Board

The three MOSFETs and all 48 LED leads meet on one 160 × 100 mm perf board, screwed to the base plate’s four stands under the LED holder. Each tier’s eight minus leads are twisted together with its MOSFET’s drain lead and soldered across three holes on one side of the board: low on the left, medium on top, high on the right. All 24 plus leads meet the same way on the bottom side, wired to 5 V, and the three sources share a joint wired to GND. Jumpers on the gates go to Arduino pins D9, D10 and D11.

4.4 Design Decisions

  • The same light in every tube of a condition. Every LED was measured one by one; the four in each column are matched within 0.4–1.8%.
  • Three clearly different intensities. Each tier’s brightness is set by PWM duty cycle in code, through its own MOSFET.
  • Fixed light for the whole run. The duty cycles are set before the run and not changed; there is no feedback in the light path.
  • No outside light. The housing encloses the LEDs and the electronics, and the tube holder closes the top.
  • No light from the neighboring well. A black tube holder with 4 wall loops replaced the white one with 2, which leaked. Not yet re‑tested.
  • The same distance every run. The tube holder seats each tube at a fixed height over its own LED.
  • Survives a night on a shaker. The base plate is held at four screw points, not two, and the solder joints are reinforced. Not yet re‑tested.
  • Simple to put together and open. The sliders go in through the housing and support both holders; twelve screws in three sizes fasten the rest, so only a screwdriver is needed (5.3).

References

The LPA is not a new idea. Lighting a plate of cultures from below, with control per well, is the Light Plate Apparatus design from the optogenetics literature1, and this LPA is named after it. We added the dual‑wavelength column layout, LEDs matched by measured output and an enclosure sized for our own tubes.

The biology, the CcaS/CcaR green/red switch, also comes from the literature; Castillo‑Hair and colleagues characterized it in Bacillus subtilis2. This page reports light in lux and does not convert it to photon flux, so these tiers are not placed on that paper’s dose scale.
